# VT screens, 2026-11-17

Rendered with vt-render from the pool of feat/vt-bar-and-key-labels (#361, pool MW28), Dutch, English and Hungarian builds, with lifelike values written into the pool for the pictures.

The pool is scaled first the way AgIsoStack scales it before the upload (VirtualTerminalClient::scale_object_pools()): the data masks from their 200 px design to the 480 px mask (fonts 12x16 -> 24x32, 8x12 -> 16x24, 8x8 -> 16x16), the soft keys 1:1 for vt-render's 60 px keys.
